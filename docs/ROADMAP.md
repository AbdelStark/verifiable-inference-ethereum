# Engineering Roadmap (`M0` to `M4`)

These rows match the repository's GitHub milestones, which hold the full scope and configuration.

| Milestone | Scope | Exit gate |
|---|---|---|
| **M0: Verified foundation** | Everything in the tree builds and passes in CI on pinned toolchains and agrees with `SPEC.md`. Speculative and unproducible code is gone. `publicDigest` commits to the tokens in place of the on-chain Fiat-Shamir replay. | CI is green on `main` with Rust 1.99.1, Foundry v1.8.6, solc 0.8.38 and `evm_version = "osaka"`; format, lint and lockfile gates run in CI and `make check`; no native Circle STARK or `SASHBIN1` code remains and M5 is marked not planned; the Solidity fixture is generated from Rust with drift detection; `publicDigest` binds the tokens; `SPEC.md` and the code agree; every negative control passes in the suites `SPEC.md` lists; the docs separate what exists from what is planned. |
| **M1: Measured local settlement on Anvil** | Mine the TinyLlama settlement on a running anvil node, and measure it. Pin `code_size_limit = 24576`, `gas_limit = 16777216` and `isolate = true` (after splitting the test contract, which is over the limit). Gate gas with committed snapshots, regenerated by `make check` and CI, and an `assertLe` budget per snapshot. Take authoritative gas from receipts on `anvil --hardfork osaka --enable-tx-gas-limit`, labelled with the hardfork and Foundry version, and publish `--gas-report` as a CI artifact. Amsterdam figures are provisional and outside the exit gate: `docs/EVM-GAS-MODEL.md` §4 records them from a Foundry nightly, and #24 re-measures them on a stable release. The docs replace their estimates with these measurements. | Dev-mode settlement is mined on local anvil under Osaka; `SashGridVerifier.verifyGrid` on the 23-segment run costs under 350k gas; every contract, test contracts included, stays under 24,576 B. |
| **M2: Real SASH proofs through an SP1 guest** | Run a verifier-only build of SASH's `verify_composed` over its vendored `nitroo` Stwo in an SP1 v6 `riscv64im` guest, one per segment. The guest rejects unsound parameters, lax or skipped gadgets, open seams, token ids `>= P` and any statement but the single token block `B0`, checks the token bindings (bound into SASH's transcript by patch 0006, which upstream `eb95bfa` lacks: `SECURITY.md` §5), and commits its segment claim, `fixedHash` and the token hashes (`tokenHash(tokIn)` on `B0L0`, `tokenHash(tokOut)` on `head`; `SPEC.md` §1.1). Decided: `fixedHash` hashes the whole parsed `Fixed` and the manifest pins it. | All 23 segments verify in the SP1 executor with cycles, peak memory and the BLAKE2s share recorded per segment; tampered and unsound bundles and token ids `>= P` are rejected; the fixture regenerated from the bundles is byte-identical to the committed one (if it differs, stop and ask); the go/no-go for M3 is recorded here. **Go/no-go: GO on SP1** (2026-10-28). Thresholds: F1, every segment within half of SP1's limits; F2, `B0L10` and `head` prove without running out of memory; C1, at most $5 per inference; C2, at most 1 h per inference with the 23 segments in parallel, aggregator and wrap included; C3, measured cycles at most 10x the earlier ~1e10 estimate. Measured on one RTX PRO 6000 (Hugging Face Jobs `rtx-pro-6000`, SP1 6.10.0): compressed proofs in 210 s (`B0L10`) and 722 s (`head`). Extrapolated: $4.10-4.25 and about 90 min per inference on one GPU, and 722 s for `head` with the segments in parallel. The aggregator and the wrap were estimates there; M3 measured them (`docs/EVM-GAS-MODEL.md` §9.4). Proving runs on Hugging Face Jobs. |
| **M3: Compressed SP1 settlement on Anvil** | Goes ahead on SP1, per M2's go/no-go. One aggregator guest verifies the 23 SP1 compressed segment proofs and commits exactly the 32-byte `publicDigest`. Settle through `Sp1SashSegmentVerifier` against the real SP1 verifier on anvil, with `allowDevVerifier = false`. Decided at M3 start (`SECURITY.md` §2 and §6): the wrap is PLONK, whose universal Aztec Ignition setup is public, where Groth16 v6.1.0 adds a circuit-specific phase 2 with 18 participants and no public call. The binding is the pinned, ownerless v6.1.0 `SP1VerifierPlonk`, not the `SP1VerifierGateway`, whose owner can route any verifier. | Aggregated settlement costs under 600k gas on Osaka, measured from a receipt on `anvil --hardfork osaka --enable-tx-gas-limit`; the Amsterdam figure is recorded; no dev mocks are on the settlement path. **Met (2026-10-30)**, `docs/EVM-GAS-MODEL.md` §5: the settlement of the TinyLlama run with its real PLONK proof costs 520,898 gas on Osaka (anvil receipt, Foundry 1.8.6); under Amsterdam it costs 604,318 gas, 4,318 above 600,000 (provisional, mined on Foundry nightly `024702852`, and not gated: the gate is Osaka's); the settlement has `allowDevVerifier = false` and the SP1 run deploys no dev verifier, which `make anvil-demo` checks. Proving per inference, measured (§9.4): $4.61 and 100.6 min on one RTX PRO 6000, or 18.9 min with the 23 segments in parallel. |
| **M4: Public testnet settlement on Hoodi** | Deploy with `allowDevVerifier = false` to Hoodi (`560048`); Sepolia (`11155111`) is optional. Fork tests assert the deployed SP1 verifier's address, `VERIFIER_HASH`, `VK_ROOT` and `VERSION` (`VERIFIER_HASH` alone does not tell Sepolia's broken v6.1.0 PLONK entry apart, `SECURITY.md` §6); `SECURITY.md` gains a pre-deployment audit checklist, including Slither. Enroll the TinyLlama manifest and submit a live verification transaction. | A finalized Hoodi transaction settles the TinyLlama run and emits `InferenceVerified` with a non-dev `VerifierKind`, with `tx.gasLimit <= 16,777,216`; the gas breakdown reproduces the receipt's `gasUsed` as `max(standard + execution, floor)`; the fork id, addresses and transaction hash are recorded. |

Native Stwo-in-Stwo recursion (M5) is not planned. It is reopened only if SASH proofs become consumable by StarkWare's circuit recursion, StarkWare publishes a Solidity S-two verifier, or a measured design fits `EIP-7825` (or a multi-transaction fact-registry design is accepted).
